# Problem Library

A catalog of 669 real math questions Hannah has actually seen, from four kinds of sources, built so a new speed-training set can be generated by shuffling fresh numbers/wording onto real question types, with every generated problem traceable back to something she really encountered.

## Sources

| Source | Count | What it is |
|---|---|---|
| `isee_official_screenshot` | 189 unique (200 w/ dup captures) | The 5 full ISEE Lower-Level Quantitative Reasoning practice tests: What to Expect (9/5), ISEE Lower #1-4 (8/30, 9/13, 9/25, 9/27) |
| `book` | 450 | Physical "Elevate Prep" workbook pages — a topic-drill book (pages 124-194) and 3 full "Practice Test" volumes (Practice Test 1/2/3) |
| `individual_exercise_screenshot` | 30 | Short 4-5 question online topic drills, including "Which value is NOT equivalent to [x]?" (fraction/decimal/percent equivalence — 4/4 wrong, consistent "missed the word NOT" pattern) |
| `platform_dashboard` | 2 (meta) | The platform's own "Hard" difficulty catalog — 28 question banks, some with real completion data |

## The confidence_tier field (book & individual-exercise entries only)

Since the 189 official-test questions are confirmed real ISEE-style training material, every book/exercise entry is cross-checked against them:

- **`verified-in-official-material`** (399 of 480) — this problem type is also confirmed to appear in the official test material, so it's realistic to expect on the real test.
- **`partial-overlap`** (81 of 480) — related to something in the official material, but not a strong match — a different specific flavor of a broader skill. Treat with more caution; not confirmed to reflect real-test content.

No entry landed in a flat "not in official material at all" tier this round — everything cataloged so far relates at least loosely to a confirmed official-test topic. That may change as more book/exercise content is added; watch for it, since the point of this field is exactly to catch cases like "Unit Conversion with Made Up Units" (a Hard-flagged platform bank with zero real problems in this library yet) that might turn out to be book/drill-only content never actually tested.

**Caveat on this field:** it's a keyword/category overlap heuristic, not a verified fact — treat a `partial-overlap` tag as "worth double-checking," not "confirmed unrealistic."

## Aggregate findings worth knowing

- **Multi-step unit conversion**: on one book drill page, single-step conversions were all correct but **7 of 10 multi-step conversions were wrong** — the cleanest, strongest confirmation of this gap in the whole project.
- **"NOT equivalent to" framing**: 4 of 4 wrong on an online drill, every time by picking an equivalent value instead of the non-equivalent one — looks like a missed-keyword habit issue, not a fractions/decimals/percent knowledge gap.
- Roughly 60 of the 450 book entries show some form of wrong-answer evidence (crossed-out/corrected circles, or a circle that doesn't match the computed correct answer) — a much larger evidence base than the official-test-only data alone.

## Schema notes

Official-test entries use `matches_known_gap`, `is_wrong`, `possible_habit_trigger`, `real_test_signal` (see earlier version of this README/memory for full definitions). Book/exercise entries additionally use `marked_answer`/`discarded_answer` (what Hannah actually circled, including self-corrections) instead of a platform-graded `is_wrong`, since books don't auto-grade — correctness there comes from either independently solving the problem (`correct_letter`) or an explicit note.

## Integrity note

Every cataloging pass (5 for the official tests, 2 for the books, 1 for the new exercises) was explicitly instructed to report "unclear" rather than invent content, following an earlier incident in this project where a research pass fabricated plausible-sounding content it couldn't verify. Samples from each pass were personally spot-checked against the original images and matched exactly, including cross-validating several entries against problems already independently confirmed earlier in this project (e.g., the page-143 "200cm" off-by-10 instance, the page-144 Unit Conversions Practice Set 2 pages).
