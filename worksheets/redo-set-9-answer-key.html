9 Second Chance: The 9 Problems from the 0920 Test
Problem 1
Serena picked a number greater than 40 but less than 50. If the number is an odd number that is divisible by 3, what number did Serena pick?
AnswerB (45)
Why: Check all three conditions: between 40 and 50, odd, and divisible by 3. 45 is odd and 4+5=9 is a multiple of 3, so 45 works. 48 is divisible by 3 but it is EVEN; 43 and 49 are odd but not divisible by 3.
Problem 2
A group of fraction bars is shown. Which list shows the fractions 2/3, 3/4, 3/6, 2/5 in order from least to greatest?
AnswerB (2/5, 3/6, 2/3, 3/4)
Why: Using the bars (or decimals): 2/5 = 0.4, 3/6 = 0.5, 2/3 = 0.67, 3/4 = 0.75. Least to greatest is 2/5, 3/6, 2/3, 3/4. Choice D lists them greatest to least, which is the reverse of what was asked.
Problem 3
Two classes, Class A and Class B, each recorded the eye color of students in the class. The graph shows the results. Which eye color was the most common?
AnswerA (blue)
Why: The question is about BOTH classes together, so add the two bars for each color: blue 5 + 6 = 11, brown 8 + 2 = 10, green 3 + 3 = 6, hazel 4 + 3 = 7. Blue is the most common. Brown has the single tallest bar, but only in Class A.
Problem 4
Volume is the space an object takes up. A box contains 27 unit cubes. There are gaps between the cubes contained in the box. Which statement best represents the volume of the box?
AnswerC (The volume of the box is greater than 27 cubic units.)
Why: Volume is the space the box takes up. The cubes take up 27 cubic units, and the gaps are extra space inside the box that is also part of its volume. So the box's volume is greater than 27 cubic units.
Problem 5
Students were asked to write a new number using all the rules below and the digits 0, 2, 4, 6, and 8.
RULES FOR THE NEW NUMBER
1. The number must have 5 digits.
2. The number must be even.
3. The number must be the smallest number possible.
4. Each number can be used only once.

What digit is in the tens place for the new number?
AnswerD (6)
Why: The smallest 5-digit number can't start with 0, so it starts with 2, then the rest go in order: 20468 (it ends in 8, so it is even). The places are: 2 ten-thousands, 0 thousands, 4 hundreds, 6 tens, 8 ones. The tens digit is 6. (2 is the ten-thousands digit.)
Problem 6
Ron is calculating how much it would cost for each of his friends to go see a movie. They shared the total cost of the tickets equally. The list shows what is known.
The number of people attending is □.
The total cost of the tickets is ○.
Which equation will determine △, the cost for each friend to attend the movie?
AnswerD (△ = ○ ÷ □)
Why: “Shared the total cost equally” means the total is split among the people, so divide: cost each = total ÷ number of people. Test it with numbers: $30 total shared by 5 people is $6 each, which is 30 ÷ 5.
Problem 7
The table shows the number of people who attended a concert on four nights. Which graph represents the data in the table?
AnswerB (Graph B (bars 175, 125, 200, 75))
Why: Check every night against the table: Night 1 = 175, Night 2 = 125, Night 3 = 200, Night 4 = 75. Graph B matches all four bars. Graph A has the same four numbers but in the wrong nights (75, 200, 125, 175). In the picture graphs each person is 50, so they would need 3.5, 2.5, 4 and 1.5 people; neither does.
Problem 8
Which number leaves a remainder of 2 when divided by both 5 and 8?
AnswerD (42)
Why: Test each choice with BOTH numbers. 42 ÷ 5 = 8 remainder 2, and 42 ÷ 8 = 5 remainder 2, so 42 works. 37 leaves 2 for 5 but 5 for 8. 38 leaves 3 and 6. 40 leaves 0 and 0.
Problem 9
Use the number pattern to answer the question.
1  3  9  27  ?  ?
What is the sixth number in the pattern?
AnswerC (243)
Why: Each number is 3 times the one before: 1, 3, 9, 27, 81, 243. The fifth number is 81 and the sixth is 243. (The rule is multiply by 3, not add and not double.)
