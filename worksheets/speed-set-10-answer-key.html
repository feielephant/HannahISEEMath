Which statement is true?
A  A rhombus is always a square.B  A rectangle is always a rhombus.C  A rhombus is always a rectangle.D  A square is always a rhombus.
Answer: D. A rhombus has 4 equal sides. A square has 4 equal sides (and 4 right angles), so every square is a rhombus. A rhombus does not need right angles, so A and C are false. A rectangle does not need equal sides, so B is false.
